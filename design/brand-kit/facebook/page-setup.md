# Thulawa News Facebook Page setup

Everything needed to create and fill in the Facebook Page.

## Images

| Field | File | Notes |
|---|---|---|
| Profile picture | `facebook-profile-720.jpg` (or `facebook-profile-2048.png`) | Facebook crops it to a circle. The seal already fits inside the circle. |
| Cover photo (recommended) | `facebook-cover-2-mobile-1640x924.jpg` | Works on mobile and desktop: the centre is kept clear for the profile picture, which Facebook centres over the bottom middle (much larger on mobile). See `facebook-cover-safe-area-guide.png`. |
| Cover photo (desktop only) | `facebook-cover-3-desktop-1640x924.jpg` | Name and tagline stacked above the small desktop profile picture. On mobile the larger profile picture covers the tagline. |
| Cover photo (classic) | `facebook-cover-1-classic-1640x924.jpg` | The first design, without the border. The profile picture covers part of the tagline on both desktop and mobile. |
| Post images | Generated by the admin **Social publishing** page (1080 × 1350) | The Canva brand kit also has an editable post template. |
| Link preview | `../web/og-image-1200x630.jpg` | Used automatically when a website link is shared. |

## Brand rules

Read `../thulawa-brand-guidelines.pdf` before making new graphics. In short:

- Use the supplied images; never retype the name or tagline in another font.
- Navy `#13233A` / deep navy `#0B1626` with gold `#C9A24A`, light gold `#E9D08C` and cream `#F5ECD8`.
- The tagline is exactly: අසමතුලිත ලෝකයකට සමතුලිත පුවත්
